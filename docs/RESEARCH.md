# 조사 지식과 한계

목표는 자료의 존재와 해석 범위를 전달하는 것입니다. 아래 내용은 현재 소스와 저장된 자료를 정리한 것이며, 새 현장 조사나 최신 외부 서비스 정책 검증을 뜻하지 않습니다. 현재 구현의 정답 여부는 별도 실험으로 판단합니다.

## 정보원과 활용

| 영역 | 현재 활용 | 무엇을 알 수 있나 | 무엇을 알 수 없나 |
|---|---|---|---|
| 도로·보행 연결 | OpenStreetMap 노드/way ID와 태그, 광역은 Geofabrik 스냅샷 | 등록된 연결·통행 제한·계단·길 종류 | 실제 공사·차단·모든 보도 연결의 완전성 |
| 고도 | Mapzen/Tilezen Terrarium, 약 31m 격자 | 지형 기반 고도·완만한 고도 변화 추정 | 정확한 보도·교량 상판 높이, 짧은 경사와 수직 정확도 |
| 횡단·신호 | 횡단 태그, 직접 신호 태그, 주변 신호 근접 추정 | 기록/추정된 신호 횡단 통과 위치·횟수 | 도착 시 신호 상태·실제 대기시간·누락 횡단 |
| 편의점·급수대 | 경로에서 직선 50m 이내 OSM 등록 시설 | 등록된 시설 근접성 | 진입 가능성·영업·실제 급수·음용 가능 여부 |
| 장소 검색 | 명시적 검색 요청 시 Photon | 검색어에 맞는 장소 좌표 | 해당 좌표가 달리기 출발 가능한 길인지 |
| 노면·조명·폭 | 해당 태그가 있는 보행로 | 등록된 특성 | 미기록 길이 어둡거나 좁거나 나쁘다는 결론 |

출처·다운로드 날짜·원본 형식 링크는 [data/ATTRIBUTION.md](../data/ATTRIBUTION.md)에 있습니다. 오래된 포항 샘플의 Overpass 요청은 저장된 조사 이력이며 앱이 실행할 때 다시 질의하지 않습니다. 광역은 정적 파일을 받습니다.

## 중요한 해석 구분

1. **선이 맞닿음과 길이 연결됨:** 실제 공유 OSM 노드에 따라 연결합니다. 겹친 좌표나 지도 그림만으로 고가도로·지하도·울타리 너머를 연결하면 안 됩니다. 스냅 거리도 연결이 검증되지 않은 접근 거리입니다.
2. **세 가지 높이 지표:** 최고–최저 차는 전체 높이 범위, 누적 상승은 반복해서 오른 양, 경사는 구간 거리 대비 높이 변화입니다. 서로 대체하지 않습니다. 0m와 결측도 다릅니다.
3. **횡단·신호·대기시간:** 전체 횡단과 신호 횡단을 분리합니다. 같은 신호를 왕복하면 두 번 통과합니다. 미확인을 무신호로 바꾸지 않습니다. 신호 수는 대기 가능성의 대리 지표입니다.
4. **세 종류의 중복:** 한 경로 안의 반복, 동시에 추천한 후보 사이의 유사성, 과거 러닝 기록과의 새로움은 다른 문제입니다. 현재 과거 러닝 기록은 사용하지 않습니다.
5. **많은 후보와 좋은 후보:** 후보 개수·묶음 개수·예쁜 모양만으로 품질을 판단하지 않습니다. 전역 최적해를 구한 것도 아닙니다.
6. **정보 부족과 불리한 조건:** 미기록을 나쁨으로 감점하지 않습니다. 현재 장점 가산은 기록이 풍부한 지역을 유리하게 만들 수 있습니다.

## 고도 처리에서 배운 것

Terrarium은 `R × 256 + G + B / 256 − 32768`로 디코딩합니다. 저장된 0.1m 단위는 정확도가 아닙니다. 기존 구현은 약 50m 간격으로 샘플링·보간하고 이웃값으로 완화합니다. 작은 고도 변화의 누적 잡음과 최고–최저 범위를 구분해 다룹니다. 교량·터널·결측 구간은 미확인으로 남깁니다. 자세한 처리는 elevation.js를 읽고, 다른 방법을 쓰면 샘플 간격과 평활화 정책도 실험 조건에 기록하세요.

## 실제로 부딪힌 문제

- 거리만 정확히 맞추려 하면 왕복 코스가 유리해져 여러 형태가 이미 발견돼도 최종 화면에 드러나지 않았습니다. 지금은 후보 생성과 제품 추천을 분리합니다.
- 같은 길을 조금 더 달려 장점 비율만 높아진 긴 경로가 선택되는 문제가 있었습니다. 현재는 실제 포함 관계의 불필요한 연장과 다른 길을 통한 우회를 구분합니다.
- 지도 중심·축척이 바뀌면 비슷한 코스가 다른 모양처럼 보였습니다. 비교할 때 동일한 지도 위치와 축척을 유지합니다.
- 이미 상위 3개나 그룹 대표를 고른 뒤 다른 기준을 비교하면 진짜 고저차·신호 최소 후보를 놓칩니다. 제품 추천은 전체 발견 후보에서 고릅니다.
- 수도권/경상권 자료를 확보해도 일부 지점에서 코스를 못 찾습니다. 현재 보행망 모델은 보수적이며 데이터 누락·분리된 연결·선택 위치·거리 조건이 영향을 줍니다. 무조건 지도 범위 문제로 진단하면 안 됩니다.
- 기다리는 시간을 줄이려고 다운로드·그래프 준비·탐색·표시를 분리했습니다. 캐시가 있는 Mac 결과를 최초 접속 iPhone 속도로 해석하면 안 됩니다.

## 아직 남은 조사

선택한 코스의 횡단·신호 매칭과 누락 확인, 지형과 실제 높이 대조, 통행 가능 여부, iPhone 성능, 점수 가중치/거리 오차의 사용자 선호는 별도 검증 대상입니다. 경치·개방감·새로움은 대로 인접성이나 도로 반복만으로 추론하지 않습니다.
