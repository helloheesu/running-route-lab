# 공유 사본 검증 기록

검증일: 2026-10-03. 환경: macOS arm64, Node v24.15.0. 기존 PoC의 추적 파일 변경이 없음을 확인했습니다. 원본의 별도 공개 검토 문서는 원래의 미추적 상태 그대로이며 공개 사이트를 수정·재배포하지 않았습니다.

## 실행과 계산

- 새 저장소를 별도 빈 폴더에 `git clone --no-local`로 클론했습니다. 원본의 node_modules, 작업 폴더, 광역 데이터, Git 이력을 복사하지 않았습니다.
- 클론에서 `npm ci`, `npm test`, `npm run data:check`, `npm run build`, `npm run check:release` 통과. npm 캐시는 새 저장소 내부에 격리했습니다.
- 자동 검사 44개 통과. 추천·신호/고도 결측·지도 경계·취소·메타데이터 정리·원본 해시·중단된 다운로드 보존/재실행 포함.
- 모바일 런타임 28개 파일 무결성 통과. 기본 빌드는 클라우드 설정 없이 정적 결과를 생성합니다.
- 정리 전후 포항 샘플의 전체 그래프와 POSTECH 5km 실행의 전체 457개 후보·최종 추천이 deep equality 비교에서 일치했습니다. 엔진을 바꾸지 않았습니다.
- `npm run bench -- --case postech-5k --runs 1` 실행 성공. 이 실행은 도구 동작 확인이며 성능 우월성이나 0.3초 달성의 근거가 아닙니다.

## 데이터 준비와 공개 목록

- 포항 6,973개 요소의 금지 메타데이터·연락처 제거 확인.
- 실제 공개 원본에서 광역 2,641개 타일을 다운로드하고 원본 SHA256/크기를 검증했습니다. 중간 네트워크 중단 후 재실행해 정리된 캐시를 재사용하고 완료했습니다.
- 완성된 모든 타일의 정리 정책·SHA256·크기·파일명을 재검사했습니다. 정리 결과 총 압축 크기는 139,315,575 bytes입니다.
- 원본의 각 타일에 정리 규칙만 적용한 결과와 내려받아 준비한 타일 2,641개가 모두 일치했습니다. 좌표·ID·필요 태그를 추가 변경하지 않았습니다.
- 완료 후 준비 명령 재실행은 완성본을 검증하고 재사용했습니다.
- 다운로드 자료·캐시·node_modules·dist가 Git 무시 대상으로 남고 공개 목록을 바꾸지 않음을 확인했습니다.
- Python 원본 빌더는 편집 메타데이터·연락처를 포함한 작은 합성 OSM 입력으로 실행해 정리된 압축 타일과 해시를 확인했습니다. JS/Python 공통 정책 결과도 일치했습니다. 국가 전체 PBF에서 모든 타일을 새로 생성하는 작업은 이번 사본 검증에서 다시 실행하지 않았습니다.
- 첫 커밋 전 공개 파일 목록 96개를 검사했습니다. 개인 절대 경로·내부 배포 식별자·검사한 비밀값 패턴과 금지 OSM 필드가 검출되지 않았습니다. 커밋 이메일은 사용자의 허용에 따라 유지했습니다.

## 브라우저

광역 자료가 없는 독립 클론을 별도 로컬 서버에서 실행했습니다. 393×852 화면에서 샘플 전용 안내, POSTECH 출발지 조정/확정, 실제 5km 계산, 지도·추천 카드 표시를 확인했습니다. 정보 부족으로 신호 최소 추천을 보류하는 표시가 나왔습니다. 브라우저 Back과 앱 Back을 섞어 결과 → 거리 → 위치 조정 → 시작으로 돌아오는 것을 확인했습니다.

## 검증의 경계

UI 예시 지표는 현장 측정값이 아닙니다. 실제 iPhone GPS/Safari 및 고도·횡단·통행 현장 대조는 미검증입니다. 정적 빌드의 JS 청크 크기 경고는 별도 최적화 대상입니다. 패턴 검사·해시·빌드 성공은 모든 개인정보 부재나 실제 현장 정확도를 보장하지 않습니다. 위 검증 시점에는 GitHub 생성/업로드를 하지 않았습니다. 이후 사용자의 요청으로 `helloheesu/running-route-lab` 공개 저장소를 만들고 업로드했습니다. 새 코드 라이선스는 부여하지 않았습니다.
