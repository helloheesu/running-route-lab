# 현재 조건과 실험 가정

## 비교에서 먼저 고정할 제품 조건

- 지정 출발지로 돌아옵니다. 순환형·일부 반복형·왕복형을 모두 허용합니다.
- 입력 1–12km, 기본 5km, UI 0.5km 단위. 발견 후보는 목표 거리 ±20%를 허용합니다.
- 기본 계단 회피, 등록된 통행 제한과 보행 방향을 지킵니다. 출발지는 100m 안의 길로 보정하고 확정 전에 거리를 표시합니다.
- 전체 발견 후보에서 **최적 코스 / 고저차 최소 / 신호 횡단 최소**의 우승자를 독립적으로 고릅니다. 같은 후보는 한 카드로 합쳐 추천 이유를 보존합니다. 최대 3개이며 3개를 억지로 채우지 않습니다.
- 최적은 현재 보정 점수 최고, 고저차는 최고–최저 고도차 최소, 신호는 등록·추정 신호 횡단 통과 횟수 최소입니다.
- 고도 일부 결측 후보는 고저차 최소에서 제외합니다. 기록된 횡단의 신호 여부가 미확인인 후보는 신호 최소에서 제외합니다. 비교 가능한 후보가 없으면 해당 추천을 보류합니다.
- 동률은 기존 점수 → 목표 거리 오차 → 후보 ID 순입니다. 비슷하다는 이유만으로 다른 기준의 우승자를 차순위로 교체하지 않습니다.
- 최적·최소는 이번에 발견한 비교 가능한 후보 안의 결과입니다. 실제 세계의 전역 최적해를 보장하지 않습니다.

## 현재 구현의 실험용 수치

이 수치는 인터뷰·현장 연구로 확정한 선호가 아닙니다. 바꾸면 후보 생성 자체의 개선과 정책 변경 효과를 구분해서 기록합니다.

- 확인된 장점 가산: 보행로 비율×20, 포장 보행로×30, 조명 있음 보행로×15, 폭 3m 이상 보행로×15, 연속 등록 보행로 최대10. 정확한 정의·제외 조건은 route-evidence.js가 기준입니다.
- 거리 보정 계수30. 실제 포함 관계에서 피할 수 있는 초과 거리 보정 계수150. strict containment 99.9%. 점수는 안전성 평가가 아닙니다.
- 일부 짧은 후보는 부족분 최대5%/300m 범위에서 제한된 추가 왕복으로 보완합니다. 원본을 보존하고 기록된 부담 증가를 비교합니다.
- 탐색기 묶음은 물리 구간·통과 횟수의 유사도와 guarded average linkage를 사용합니다. 평균 .65, 모든 쌍 최저 .50은 실험 설정입니다. 제품의 세 기준 선택 전에 이 대표들만 남기지 않습니다.
- 신호 근접 추정 28m, 시설 직선 근접 50m도 구현상의 설정입니다.

## 표시와 입력 상태

고저차·신호 레이어는 기본 켜짐, 편의점·급수대는 꺼짐입니다. 높낮이는 URL variant=A, 경사 방향+크기는 B이며 C는 B 호환 별칭입니다. 빨강 오르막·파랑 내리막·진할수록 가파름, ±3%는 중립입니다. 표현·레이어 변경은 추천을 다시 계산하거나 지도를 이동하지 않습니다.

고정 case 링크는 시연용 수치를 포함합니다. 출발지나 거리를 확정해 바꾸면 실제 계산으로 전환합니다. 임시 선택과 확정 상태를 분리하고 늦은 비동기 응답이 새 입력을 덮지 않게 합니다. 시작 버튼은 확인 단계까지만 진행하며 주행 기록/내비게이션은 범위 밖입니다.
